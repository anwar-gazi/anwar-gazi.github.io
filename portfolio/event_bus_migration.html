Chapter 01

The Coupling Bottleneck

Legacy task navigation relied on strict vertical orchestration. The instruction to "Open a Task" had to manually tunnel through a rigid hierarchy: Root → Board → Column → Card.

This created architectural fragility. Intermediate components became glorified conduits for callbacks they never used, while leaf nodes were impossible to test in isolation without heavy mocking.
